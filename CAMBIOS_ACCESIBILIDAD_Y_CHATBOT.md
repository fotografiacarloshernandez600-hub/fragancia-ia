# Cambios realizados
- Paleta azul de alto contraste con acentos rosados y amarillos, textos más grandes, foco de teclado visible y animaciones respetando reducción de movimiento.
- Asistente SQLite con sinónimos, tolerancia a faltas simples, consultas por fechas, productos concretos, precios, inventario, ranking y pedidos.
- Sin APIs externas ni ejecución de SQL libre. Las preguntas ajenas a las tablas no pueden responderse como si fueran datos reales.
- Se conservaron rutas, modelos, compras, autenticación y estructura de base de datos.
