# FRAG-IA Motion Edition

Se conservaron la paleta rosa/champan, las rutas Flask y SQLite.

Mejoras: cabecera flotante al desplazarse, progreso de lectura, entradas al aparecer, animacion del frasco, brillos suaves, tarjetas con elevacion, transiciones de botones y productos, nueva seccion editorial, mejoras en dashboard y movimiento adaptable a pantallas pequenas.

Se respeta `prefers-reduced-motion` para accesibilidad. No se agregaron librerias JS ni APIs de pago.

En PowerShell inicia con ` .\INICIAR_WINDOWS.bat `. Es necesario instalar Python previamente.
